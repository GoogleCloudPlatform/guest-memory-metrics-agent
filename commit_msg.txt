Prepare Guest-Memory-Metrics-Agent for open-source (Copybara export)

This CL contains a variety of fixes to make the project build and run properly
as an open-source project once exported by Copybara:

1. Copy.bara.sky additions:
   - Added `core.replace` transformations to appropriately replace internal Google paths
     (like ``) with root paths.
   - Replaced internal `absl` targets with `@com_google_absl//absl/...` imports.
   - Translated `rules_cc` loads.

2. C++17 compatibility fixes:
   - Changed `snapshot.metrics.contains()` (C++20) to `snapshot.metrics.count() > 0`
     (C++17) in `cgroup_provider.cc` because OSS Bazel currently defaults to C++17.

3. Restored fully qualified internal paths:
   - Brought back `...` include paths and
     internal BUILD loads in the Google3 source to ensure the internal build passes.
   - Copybara export steps will strip these out.

4. Open-source build files:
   - Added `WORKSPACE` and `MODULE.bazel` to fetch OSS dependencies for external Bazel users.

5. Scrubbed Internal Info:
   - Removed instructions intended only for Googlers from README.md.
   - Updated deployment instructions (gcloud).

Tested by running OSS Bazel internally via a simulated Copybara flattened layout.
